# Техническое SEO сайта

Основной адрес: https://ivanivorontsov-sudo.github.io/

## Что настроено

- Уникальные title и meta description для основных страниц.
- Архивная исследовательская страница `/aefh/` (v3.1.1) и актуальная `/aefh/v5/`: self-canonical, ScholarlyArticle JSON-LD, Open Graph, Twitter Card, семантическая разметка, мобильная вёрстка и записи в корневом sitemap. Для v5.0 отдельно опубликован Python-тестовый стенд и GitHub Actions.
- Самоссылочные canonical URL для индексируемых страниц.
- Open Graph и Twitter Card для предпросмотров ссылок.
- Schema.org JSON-LD: WebSite, CollectionPage, ItemList, WebApplication, VideoGame, WebPage и хлебные крошки там, где это уместно.
- robots.txt с адресом XML sitemap.
- XML sitemap содержит опубликованные страницы корневого сайта и его проектных GitHub Pages.
- Пользовательская страница 404 с noindex.
- Каталог содержит 100 карточек непосредственно в HTML; JavaScript отвечает только за фильтрацию.
- Для десяти категорий созданы отдельные индексируемые страницы с собственными описаниями и списками сервисов.
- Каталог и веб-мастерская используют хлебные крошки и структурированные данные Schema.org.
- SEO-аудитор проверяет язык, viewport, alt, безопасные внешние ссылки, метаданные, локальные ссылки и sitemap.
- Встроенный JavaScript проверяется Node.js-парсером без выполнения кода.
- GitHub Actions запускает SEO- и синтаксические проверки при push и pull request в main.

## Проверка перед публикацией

Запустить локально:

    python3 scripts/seo_audit.py
    node scripts/check_inline_js.mjs

Проверка контролирует:
- ровно один заголовок страницы, описание и canonical;
- один H1;
- уникальность canonical URL;
- согласованность Open Graph и Twitter метаданных;
- синтаксис JSON-LD;
- локальные ссылки, ведущие на файлы текущего репозитория;
- валидность sitemap, отсутствие дубликатов и наличие всех индексируемых локальных страниц в карте сайта.

Страницы по путям vizitka/, edinicy/, tools-portal/ и supersmart-privacy/ публикуются из отдельных репозиториев GitHub Pages. Их содержимое проверяется в соответствующих репозиториях; основной скрипт не пытается считать их файлами корневого репозитория.

## Google Search Console

1. Добавить ресурс типа URL-prefix: https://ivanivorontsov-sudo.github.io/
2. Подтвердить право собственности способом, который предложит Search Console.
3. Отправить sitemap: https://ivanivorontsov-sudo.github.io/sitemap.xml
4. Проверить главную страницу, каталог инструментов и страницы веб-приложений через URL Inspection.
5. После переобхода смотреть отчёты Pages, Sitemaps и Enhancements, если для страницы доступна соответствующая функция.

Наличие sitemap и корректных метаданных помогает поисковым системам обнаруживать и интерпретировать страницы, но не гарантирует индексацию или конкретные позиции в выдаче.


## Категории каталога

Десять категорий опубликованы отдельными страницами в `tools-audit/categories/`. На каждой странице будет собственное описание, список из десяти программ, ссылки на карточки полного каталога, canonical, Open Graph, Twitter Card и Schema.org CollectionPage/ItemList/BreadcrumbList. Все адреса включены в `sitemap.xml`.

Поиск и фильтры применяются к готовым HTML-карточкам. Параметры `q`, `category`, `tag` и `quick` сохраняются в URL через History API, поэтому отфильтрованным представлением можно делиться ссылкой. Без JavaScript весь каталог остаётся видимым.

## Дополнительные проверки

SEO-аудитор выводит предупреждения для отсутствующего `lang`, viewport, alt у изображений, небезопасных ссылок с `target="_blank"` и скачков уровней заголовков. `scripts/check_inline_js.mjs` проверяет синтаксис встроенного JavaScript во всех HTML-файлах без выполнения кода.


## Локальная браузерная мастерская

Страница `tools-audit/web-tools.html` содержит 100 локальных операций в десяти категориях: текст, очистка, сравнение, кодирование, JSON/CSV/XML, URL, разработка, дата и время, математика и цвет. Реализация использует встроенные браузерные API без внешних CDN и серверной обработки пользовательского ввода. `tools-audit/web-tools.js` проверяется `node --check` в GitHub Actions.


## Карантин однотипных конвертеров

90 страниц в `tools-audit/workshop/converters/` сохранены доступными для пользователей, но каждая помечена `noindex,follow` и исключена из `sitemap.xml`. Это не удаляет инструменты и не запрещает обход внутренних ссылок. Возвращать отдельный конвертер в индекс следует после проверки полезности страницы, уникальности объяснений и корректности самого инструмента.

## Генерация sitemap и IndexNow

`scripts/generate_sitemap.py` пересобирает карту по индексируемым HTML-страницам и сохраняет известные адреса отдельно размещённых GitHub Pages. Команда `python3 scripts/generate_sitemap.py --check` используется в CI для проверки актуальности карты.

`scripts/notify_indexnow.py` сообщает участникам IndexNow об изменившихся индексируемых HTML-адресах (не более 100 за push). Уведомление означает получение списка адресов, но не гарантирует обход, индексацию или позиции в выдаче.

В `robots.txt` добавлен `Clean-param` Яндекса для распространённых рекламных меток и идентификаторов переходов. Эти параметры не должны менять основное содержимое страницы.
