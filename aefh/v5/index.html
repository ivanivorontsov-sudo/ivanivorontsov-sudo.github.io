От одного функционала относительной энтропии и аффинности Петца — к фундаментальному и присоединённому секторам Вильсона, компактному U(1) и реберной CPN-кинетике.

Аннотация

Версия 5.0 расширяет Haar-усреднённую конструкцию AEFH с присоединённого сектора до смешанного фундаментально-присоединённого действия Вильсона. Расширенный зонд на пространстве ℂN ⊕ ℂ содержит когерентность между фундаментальным блоком и опорным вакуумным сектором. Эта когерентность делает действие чувствительным к центральным фазам и при N = 1 даёт компактное U(1)-действие. Пространственно-зависимый зонд ранга 1 задаёт реберное действие, пропорциональное метрике Фубини — Штуди на CPN.

Iα(ρ,σ) = S(ρ ‖ σ) + α(1 − F1/2(ρ,σ)),   α ≥ 0 F1/2(ρ,σ) = τ(ρ1/2σ1/2)

Здесь F1/2 — аффинность Петца (квантовая аффинность Хеллингера), а не fidelity Ульмана. Следы нормированы: τn(X) = Tr(X)/n. Теоремы 9 и 10 ниже формулируются как точные утверждения о конечномерных матрицах, Haar-усреднении и гладких полях в заданной решёточной постановке.

Уточнения, перенесённые из v4.0.1

Теорема 6. Центральные вероятности pq описывают распределение по центральным секторам. Их отождествление с физическими граничными потоками требует отдельного физического постулата, связывающего центральные проекторы с операторами потока.

Теорема 7. Величина Sdim = Σqpq ln dq называется вкладом размерности неабелевых представлений, а не топологическим инвариантом. Точное условие: Sdim > 0 тогда и только тогда, когда существует q с pq > 0 и dq > 1. Для U(1) этот вклад размерности равен нулю, но шенноновская часть H(p) = −Σqpqln pq может быть положительной.

Теорема 8. Остаток O(a6) относится к одной центрированной плакетке; после суммирования по четырёхмерной решётке глобальная погрешность обычно имеет порядок O(a2). Результат называется индуцированным присоединённым действием Вильсона. Предел σ0 → I переводит коэффициент жёсткости к нулю и формально соответствует сильной связи; это не доказательство конфайнмента.

Общие определения Теоремы 9

Пусть N ≥ 1, D = N + 1 и Haug = ℂNfund ⊕ ℂvac. На MD(ℂ) используется нормированный след τD(X) = Tr(X)/D. Пусть Σ0 > 0 и τD(Σ0) = 1.

Σ0 = [ A v ; v† c ],   log Σ0 = [ L w ; w† ℓ ], Σ01/2 = [ B u ; u† d ]. A,L,B ∈ MN(ℂ),   v,w,u ∈ ℂN,   c,d > 0,   ℓ ∈ ℝ.

Для W,V ∈ U(N) положим W̃ = W ⊕ 1 и Ṽ = V ⊕ 1. Определим Haar-усреднённое действие

Sα,Σ₀fund(W) = ∫U(N) dV Iα( W̃ Ṽ Σ₀ Ṽ† W̃† , Ṽ Σ₀ Ṽ† ).

Теорема 9. Индуцированное фундаментально-присоединённое действие Вильсона

Точное Haar-усреднение

Для N ≥ 2 введём нормированный характер присоединённого представления

τadj(W) = ( |Tr W|2 − 1 ) / (N2 − 1).

Тогда для любого W ∈ U(N)

Sα,Σ₀fund(W) = κfund(1 − Re τN(W)) + κadj(1 − τadj(W)).

Для N = 1 присоединённое слагаемое отсутствует. Коэффициенты равны

κfund = 2/(N+1) · ( Re(v†w) + α‖u‖2 ), κadj = 1/(N+1) · [ Tr(AL) − Tr(A)Tr(L)/N + α( Tr(B2) − (Tr B)2/N ) ].

Все величины в скобках вещественны при указанных положительных матрицах. При α ≥ 0 выполняется

κfund = ½ Iα(ZΣ0Z, Σ0) ≥ 0,   Z = IN ⊕ (−1),

причём κfund > 0 тогда и только тогда, когда v ≠ 0. Коэффициент κadj по отдельности может быть отрицательным для некоторых зондов; физически значимая квадратичная жёсткость полного действия рассматривается ниже.

Унитарный 2-дизайн

Подынтегральное выражение после сведения к сопряжению U = V†WV имеет полиномиальную степень не выше (2,2) по элементам V и их комплексно-сопряжённым. Поэтому Haar-среднее воспроизводится точно любым точным унитарным 2-дизайном в U(N). Для N = 2 используется 24-элементная проективная группа Клиффорда одного кубита.

Компактный U(1) и центр ZN

Абелев случай N = 1
W = eiθ,   S(W) = κfund(1 − cos θ).

Это точное компактное плакеточное действие Вильсона для U(1); его гладкий слабополевой предел квадратичен по электромагнитной кривизне.

Центральный элемент N ≥ 2
S(zIN) = κfund(1 − cos(2πk/N)) > 0

Для z = exp(2πik/N), k = 1,…,N−1, и v ≠ 0 действие чувствительно к центру. Присоединённый член сам по себе остаётся слепым к ZN.

Непрерывный предел и положительность SU(N)-жёсткости

Пусть Aμ = aμIN + Âμ — гладкое эрмитово U(N)-поле, Tr Âμ = 0, а Fμν = fμνIN + F̂μν. Для центрированной плакетки с гладкими связностями

1 − Re τN(Wμν) = a4 fμν2/2 + a4 Tr(F̂μν2)/(2N) + O(a6), 1 − τadj(Wμν) = [N/(N2−1)] a4 Tr(F̂μν2) + O(a6).

Поэтому локальное действие одной плакетки имеет вид

S□ = a4{ κfund fμν2/2 + CSU(N) Tr(F̂μν2) } + O(a6),
CSU(N) = κfund/(2N) + Nκadj/(N2−1).

Остаток O(a6) здесь локален: он относится к одной плакетке. При суммировании по O(a−4) плакеткам в четырёх измерениях глобальная ошибка дискретизации имеет типичный порядок O(a2).

Если Tr(X2) = 1 для ненулевого эрмитова бесследового X, то CSU(N) — коэффициент ε2 в S(eiεX). Из положительности гессиана Iα при α ≥ 0 следует CSU(N) > 0 для любого зонда, не инвариантного относительно вложенного действия U(N). Это остаётся верным даже когда κadj < 0: отрицательный вклад отдельного разложения не равен отрицательной полной жёсткости.

Глобальная группа. На уровне алгебр Ли u(N) = u(1) ⊕ su(N), но глобально U(N) ≅ (U(1) × SU(N))/ZN, а не прямое произведение без факторизации.

Когерентный зонд ранга 1

Пусть

Σ0 = μ0IN+1 + μ1|ψ0⟩⟨ψ0|,   |ψ0⟩ = (sin θ0 eN, cos θ0)T,

где μ0, μ1 > 0, μ0 + μ1/(N+1) = 1 и 0 < θ0 < π/2. Обозначим

Λα = 1/(N+1)[ μ1 ln(1 + μ1/μ0) + α(√(μ0+μ1) − √μ0)2 ] > 0.

Прямая подстановка в формулы коэффициентов даёт

κfund = 2Λα sin2θ0 cos2θ0, κadj = [(N−1)/N] Λα sin4θ0   (N ≥ 2).

Оба коэффициента строго положительны при 0 < θ0 < π/2. В частности, для N = 2 имеем κadj = Λαsin4θ0/2; для N = 3 — 2Λαsin4θ0/3.

Теорема 10. Индуцированное CPN-реберное действие и механизм Хиггса

Когерентный зонд как поле состояний

Пусть ψ(x) = (φ(x), χ(x))T ∈ ℂN ⊕ ℂ — гладкий единичный вектор, определённый с точностью до локальной фазы. Зададим

Σ(ψ(x)) = μ0IN+1 + μ1|ψ(x)⟩⟨ψ(x)|.

При g̃(x) = g(x) ⊕ 1, g(x) ∈ U(N), имеем φ(x) ↦ g(x)φ(x), χ(x) ↦ χ(x). Таким образом, когерентность между заряженным блоком и опорным вакуумным направлением преобразуется как фундаментальный мультиплет. В математической модели ψ(x) является CPN-значной коллективной переменной; её пространственная динамика — дополнительная степень свободы модели, хотя функционал Iα и матричная параметризация зонда остаются прежними.

Точное реберное тождество Фубини — Штуди

Для соседних узлов x± = x0 ± aμ̂/2 и Ũμ = Uμ ⊕ 1 определим

Llink(x0,μ;a) = Iα( ŨμΣ(ψ+)Ũμ†, Σ(ψ−) ).

Для любых единичных ψ1, ψ2 точное равенство имеет вид

Iα(Σ(ψ2),Σ(ψ1)) = Λα(1 − |⟨ψ1|ψ2⟩|2).

Следовательно, для ребра

Llink = Λα(1 − |⟨ψ−|Ũμ|ψ+⟩|2).

Это выражение точно инвариантно относительно локальных U(N)-преобразований на концах ребра и локальных фаз ψ(x) ↦ eiϕ(x)ψ(x). При обращении ориентации ребра оно не меняется.

Гладкий предел

Для гладких полей и D̃μψ = (Dμφ, ∂μχ)T, Dμφ = (∂μ + iAμ)φ, получается

Llink = a2Λα[‖D̃μψ‖2 − |⟨ψ,D̃μψ⟩|2] + O(a4).

В квадратных скобках находится метрика Фубини — Штуди на CPN, сопряжённая с калибровочной связностью. Для решёточного функционала Σx,μa2Llink глобальная ошибка в гладком четырёхмерном пределе имеет порядок O(a2).

Массовая форма и остаточная группа

В однородном фоне ψ0 = (sin θ0eN, cos θ0)T квадратичная форма по эрмитовой U(N)-связности Aμ равна

Lmass = Λαsin2θ0[ Σj=1N−1|(Aμ)jN|2 + cos2θ0(Aμ)NN2 ].

Стабилизатор выбранного направления изоморфен U(N−1). В квадратичном спектре остаются (N−1)2 нулевых мод и 2N−1 положительных мод. Это утверждение о гессиане в однородном фоне; оно не означает, что полная квантовая теория или её спектр уже построены.

Электрослабый случай N = 2

Положим Aμ = ½(BμI2 + Wμaσa), Wμa = g Ŵμa, Bμ = g′ B̂μ, с нормировками

1/g′2 = κfund/4,   1/g2 = κfund/4 + 2κadj/3.

Нулевая собственная мода квадратичного гессиана направлена вдоль

Âμem = (g′Ŵμ3 + gB̂μ)/√(g2+g′2),   Q = diag(1,0).

Она строго безмассовая на уровне указанного квадратичного действия: mγ2 = 0. Ортогональная комбинация

Ẑμ = (gŴμ3 − g′B̂μ)/√(g2+g′2)

и два заряженных направления имеют положительные квадратичные массы

mW2 = (Λα/2)g2sin2θ0,
mZ2 = (Λα/2)(g2+g′2)sin2θ0cos2θ0.

Для определённого стандартным образом кастодиального отношения

ρcust = mW2 / (mZ2 cos2θW) = 1/cos2θ0.
Исправление алгебры угла Вайнберга. Из указанных коэффициентов для N = 2 следуют κfund = 2Λαsin2θ0cos2θ0 и κadj = ½Λαsin4θ0. Поэтому
tan2θW = g′2/g2 = 1 + (2/3)tan2θ0,
а не 1 + (2/3)cot2θ0. Следовательно, sin2θW > 1/2. Например, при θ0 = 0.42 получается sin2θW ≈ 0.5312. Это свойство минимальной модели, а не совпадение с наблюдаемым значением Стандартной модели.

Технические замечания к доказательствам

  • Чётность центрированной плакетки. При принятом порядке множителей переход a ↦ −a циклически переставляет множители плакетки. Поэтому Tr W(−a) = Tr W(a) по цикличности следа. В общем случае не следует заменять эту аргументацию утверждением о сопряжении W(−a) и W(a) одним и тем же произведением U1U2: такое тождество не следует из одних только четырёх произвольных унитарных множителей.
  • Физический смысл фундаментального члена. Ненулевая когерентность v превращает блоковое сопряжение в чувствительный к центру пробный функционал. Это даёт фундаментальный характер в эффективном действии, но само по себе не строит динамический спектр фермионной материи и не доказывает наличие всех физических носителей фундаментального заряда.
  • Массы. Значения mW, mZ — коэффициенты квадратичной формы (деревянный гессиан) около выбранного однородного фона. Полная квантовая масса как положение полюса пропагатора требует квантовой динамики, фиксации калибровки и анализа поправок.

Верификационный стенд

К рукописи приложен Python-скрипт aefh_v5_higgs_u1_tests.py (NumPy и стандартная библиотека). В нём заявлены четыре группы проверок:

  1. Точное сравнение Haar-усреднения с 24-элементным 2-дизайном для общего положительного зонда U(2), тест U(1), центральных элементов Z2/Z3, экзотического зонда с κadj < 0 при положительной полной SU(2)-жёсткости, а также Haar Monte Carlo для U(3).
  2. Порядок локального остатка O(a6) для центрированных U(1)- и U(2)-плакеток, чётность и локальная калибровочная инвариантность.
  3. Точное CPN-тождество Фубини — Штуди, локальная калибровочная и фазовая инвариантность ребра и остаток O(a4) в локальном реберном действии.
  4. Численный гессиан массовой формы для U(2) и U(3), включая нулевую фотонную моду, число массовых/безмассовых мод и кастодиальное соотношение.
Исходный файл тестов

Скрипт доступен отдельно и не загружается браузером на этой странице.

Открыть aefh_v5_higgs_u1_tests.py

Массовые матрицы в скрипте оцениваются конечными разностями при eps = 10−4; поэтому нулевые собственные значения проверяются с численным допуском 10−6. Сам точный ноль фотонной моды следует аналитически из того, что генератор Q = diag(1,0) стабилизирует выбранный фон. Наличие исходного скрипта не означает, что тесты уже выполнены в CI или что численные проверки доказывают утверждения для всех N, всех гладких связностей или всех положительных зондов.

Что эта версия пока не доказывает

  • Не выводит полный сектор Стандартной модели. В конструкции заданы калибровочная группа U(N), решёточные связи и выбранное семейство пробных состояний. В частности, SU(3)×SU(2)×U(1), набор представлений материи и их гиперзаряды из одного этого вывода не возникают автоматически.
  • Не содержит фермионного сектора. Киральность, спектральная тройка Конна, оператор Дирака, матрицы Юкавы и сокращение калибровочных аномалий остаются отдельной задачей.
  • Не выводит потенциал Хиггса. Угол θ0 и однородный фон заданы. Реберное действие даёт CPN-кинетику и квадратичную массовую форму, но само по себе не выбирает вакуумное значение и не доказывает мексиканский потенциал или наблюдаемую массу радиального скаляра.
  • Поле CPN введено как динамическая переменная. Оно параметризует семейство состояний одного и того же матричного зонда, но математически остаётся новым полевым сектором/коллективной модой. Поэтому точнее говорить «тот же функционал Iα применён к расширенному семейству состояний», а не «динамических переменных не добавлено».
  • Сильная связь не равна доказанному конфайнменту. Для вывода конфайнмента потребуются мера интегрирования по связностям, оценка петли Вильсона/натяжения струны и анализ фазовой структуры.

Следующий открытый этаж: v6.0

Естественное продолжение — фермионный и киральный сектор: конечная спектральная тройка (A,HF,DF), структура левых и правых мод, допустимые представления, матрицы Юкавы и условия сокращения аномалий. До получения этих конструкций это программа дальнейшей работы, а не результат v5.0.
