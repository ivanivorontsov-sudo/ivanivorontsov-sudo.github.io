# Ежедневная мастерская — 11 локальных веб-инструментов

Открыть: https://ivanivorontsov-sudo.github.io/daily-tools/

Набор небольших инструментов для повседневных задач. Без регистрации, рекламных блоков, подписок, API-ключей и сторонних библиотек.

## Инструменты

1. Сравнение двух текстов с выделением добавленных и удалённых строк.
2. Контрольные суммы файлов SHA-256 и SHA-512.
3. Поиск одинаковых файлов по содержимому (SHA-256).
4. Сжатие фото с целевым размером в КБ.
5. Удаление EXIF и встроенных метаданных фото через декодирование и повторный экспорт.
6. Изменение размера фото с режимами вписывания и кадрирования.
7. Преобразование CSV ↔ JSON с поддержкой кавычек и полей с разделителями/переносами строк.
8. Безопасный предпросмотр Markdown (исходный HTML экранируется).
9. Разбор URL, просмотр параметров и сборка параметров запроса.
10. Очистка пробелов и повторяющихся строк.
11. Проверка контрастности цвета по порогам WCAG.

## Приватность

Весь JavaScript поставляется вместе со страницей. Для инструментов не подключаются сторонние API, библиотеки, рекламные SDK или аналитика. Выбранные файлы читаются через браузерные API и обрабатываются локально. Текст остаётся в текущей вкладке. Данные файлов, текстовые поля и результаты не отправляются на сервер и не сохраняются в аккаунт.

Единственное значение, которое страница сохраняет через localStorage, — выбранная цветовая тема. Технические запросы к GitHub Pages могут обрабатываться GitHub по собственной политике.

Подробности: [политика конфиденциальности](privacy.html).

## Ограничения

- Для вычисления хешей требуется Web Crypto API; на GitHub Pages сайт работает по HTTPS.
- Сжатие изображений использует возможности Canvas браузера. Фактический размер зависит от содержимого; заданный лимит может быть недостижимым.
- Повторный экспорт фото очищает стандартные метаданные, но не скрывает сведения, видимые на самом снимке. GIF-анимация может свестись к одному кадру.
- При изменении размера поддерживаются форматы, которые браузер способен декодировать.
- Сравнение текста работает построчно. Для очень больших текстов используется упрощённое сравнение общего начала и конца.
- CSV использует первую строку как заголовок; сложные типы данных и схемы таблиц не сохраняются.

## Технологии

HTML, CSS и Vanilla JavaScript; File API, Canvas API, Web Crypto API, URL API, Blob API. Никаких серверных функций для обработки данных.
