01

Сравнение двух текстов

Показывает добавленные и удалённые строки. Для черновиков, договоров и кода.

Сравнение построчное. Для очень больших текстов используется упрощённый режим.

02

Контрольная сумма файлов

SHA-256 и SHA-512 для проверки скачанных файлов.

Web Crypto API доступен на HTTPS.

03

Поиск одинаковых файлов

Сравнивает содержимое по SHA-256, а не только имена.

Файлы не удаляются.

04

Сжатие фото до нужного размера

Подгоняет изображение под лимит в КБ, меняя качество и размеры.

Целевой размер — ориентир: для некоторых изображений лимит недостижим.

05

Удаление EXIF и метаданных фото

Создаёт новый файл без исходных EXIF-метаданных.

GIF-анимация может стать статичной. Очистка метаданных не скрывает то, что видно на самом снимке.

06

Изменение размера фото

Точная ширина и высота: вписать целиком или кадрировать.

07

CSV ↔ JSON

Кавычки, запятые и переносы строк внутри полей учитываются.

Первая строка CSV используется как заголовок. JSON ожидается в виде массива объектов.

08

Markdown — предпросмотр

Пиши разметку и сразу смотри результат.

Предпросмотр

Исходный HTML экранируется; поддерживаются заголовки, списки, цитаты, код, жирный/курсивный текст и простые ссылки.

09

Разбор URL и параметров

Протокол, домен, путь, параметры и сборка ссылки.

Указанный адрес не открывается и не запрашивается.

10

Очистка и нормализация текста

Лишние пробелы, пустые строки и повторы.

11

Проверка контрастности WCAG

Проверяет читаемость цвета текста на фоне.

Пример текста для проверки

WCAG AA: 4,5:1 для обычного текста и 3:1 для крупного. AAA: 7:1 и 4,5:1.

Все одиннадцать инструментов работают в браузере. Файлы и введённый текст не отправляются на сервер. Для работы не нужны внешние библиотеки, API-ключи или сторонние загрузки.
