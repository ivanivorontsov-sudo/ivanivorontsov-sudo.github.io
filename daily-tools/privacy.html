Политика конфиденциальности Ежедневной мастерской

Последнее обновление: 9 ноября 2026 года

Открытый исходный код: исходники страницы и инструментов доступны для проверки в публичном репозитории GitHub. Автор не получает автоматически файлы, тексты, хеши и результаты обработки. Они остаются в браузере пользователя; обычные технические запросы к хостингу обрабатывает GitHub по собственной политике.

Кратко: Файлы, тексты, URL и результаты обрабатываются локально в браузере и не отправляются владельцу сайта. Я самостоятельно не собираю данные пользователей и не веду собственные базы посетителей, аккаунты, профили, рекламные трекеры, системы аналитики или журналы активности. При работе сайта, продукта или отдельной функции независимые сторонние сервисы (например, хостинг, CDN, внешний API, почтовый или AI-провайдер) могут самостоятельно получать технические сведения о запросах и данные, которые пользователь напрямую направляет им через соответствующую функцию. Эти сведения обрабатываются на стороне соответствующего сервиса и по его правилам. Я не получаю и не имею доступа к их техническим журналам, внутренним логам и базам данных; содержимое запросов, отправленных напрямую внешнему API или AI-провайдеру, также не поступает мне. Исключение — информация, которую вы добровольно отправляете мне напрямую, например письмо на контактный адрес: такое сообщение и его вложения я получаю, чтобы ответить на обращение. Страница не использует сторонние API для обработки файлов.

1. Данные и файлы пользователя

В зависимости от инструмента посетитель может выбрать файлы, ввести тексты, URL, значения цветов или CSV/JSON-данные. Эти сведения используются только для выполнения запрошенного расчёта или преобразования в браузере пользователя. JavaScript страницы не отправляет содержимое файлов, значения полей, хеши, результаты сравнения, URL или изображения на сервер владельца сайта.

Для контрольных сумм и поиска дубликатов файлы читаются через File API и обрабатываются Web Crypto API. Для фотографий применяются createImageBitmap и Canvas API. Результат создаётся в памяти вкладки и может быть сохранён пользователем на своё устройство через обычную загрузку браузера.

2. Хранение данных

Сайт не создаёт учётных записей и не ведёт собственную базу пользовательских документов или текстов. Загруженные файлы и результаты находятся в памяти вкладки и удаляются браузером при закрытии или перезагрузке страницы. Тексты остаются в полях текущей страницы; сайт не сохраняет их в localStorage, cookies или на сервере.

Единственное значение, сохраняемое страницей в localStorage, — цветовая тема интерфейса. Это значение не содержит файлов, введённого текста или идентификатора пользователя и не отправляется владельцу сайта.

3. Сетевые обращения и библиотеки

Страница не загружает библиотеки с внешних CDN, рекламные SDK, аналитику или API. Две открытые библиотеки — Papa Parse 5.7.1 (MIT) для корректного CSV и ExifReader (MPL-2.0) для чтения EXIF — размещены локально в папке vendor/ того же сайта. Они исполняются в браузере и получают выбранные данные только для локального разбора; библиотеки не отправляют их своим разработчикам. Их версии, исходные лицензии и файлы включены в публичный репозиторий. Остальные операции используют встроенные браузерные API.

EXIF-анализатор показывает основные метаданные: тип файла, размеры, камеру, дату и GPS-поля при наличии. Если GPS-метки найдены, интерфейс предупреждает, что они могут раскрыть место съёмки. Значения тегов считаются недоверенными данными и выводятся как текст, а не как HTML.

Кнопка в верхней карточке поддержки копирует опубликованный номер карты в буфер обмена устройства только после нажатия. Страница не читает буфер обмена и не отправляет его содержимое. Перевод выполняется отдельно в выбранном банке; сайт не принимает и не обрабатывает платёж.

Сайт размещён на GitHub Pages. GitHub как хостинг может самостоятельно обрабатывать техническую информацию о запросах к своим серверам (например, IP-адрес, время обращения, запрошенный ресурс и параметры браузера) в соответствии со своей политикой конфиденциальности. Владелец сайта не получает журналы хостинга и не ведёт собственную базу посетителей.

4. Ограничения

Обработка фотографий через Canvas создаёт новый файл из декодированных пикселей и не переносит исходные EXIF-метаданные, но не скрывает сведения, видимые на самом снимке. При пересохранении GIF-анимация может быть преобразована в статическое изображение. Сжатие до целевого размера не гарантируется для любого изображения.

Хеш SHA-256/SHA-512 помогает сравнивать целостность файлов, но сам по себе не доказывает безопасность файла или достоверность его источника. Сравнение текстов работает построчно и при превышении установленного объёма переходит в упрощённый режим.

5. Правовая рамка и границы уведомления

Это уведомление описывает фактическую работу данного веб-инструмента, но само по себе не определяет статус оператора персональных данных и не подтверждает соблюдение всех обязанностей по законодательству. По 152-ФЗ статус оператора зависит от того, кто организует обработку и определяет её цели и действия с данными; он не определяется одной лишь формой собственности или отсутствием собственной базы. При добавлении регистрации, аналитики, отправки форм или иных функций, собирающих персональные данные граждан РФ, необходимо отдельно оценить требования к локализации баз данных (часть 5 статьи 18), уведомлению Роскомнадзора (статья 22), опубликованию политики (статья 18.1) и трансграничной передаче (статья 12, редакция с изменениями Федерального закона № 265-ФЗ от 26.07.2026). Область применения GDPR зависит от критериев его статьи 3; одной доступности сайта из ЕС недостаточно для автоматического вывода о применимости всех его норм. Это информационное уведомление, а не юридическое заключение.

Карточка поддержки сайта

На странице Daily Tools показывается общая верхняя карточка со ссылкой на единый раздел реквизитов главного сайта. На подстраницах нет банковских номеров; карточка не считывает буфер обмена, не принимает платежи и не подключает платёжный API. Перевод пользователь выполняет отдельно через выбранный банк.
