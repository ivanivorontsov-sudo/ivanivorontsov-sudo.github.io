Политика конфиденциальности Ежедневной мастерской

Последнее обновление: 9 ноября 2026 года

Кратко: выбранные пользователем файлы и введённые тексты обрабатываются в текущей вкладке браузера. Страница не отправляет их на сервер, не использует регистрацию, рекламу, собственную аналитику или сторонние API. Выбранная цветовая тема сохраняется в localStorage.

1. Данные и файлы пользователя

В зависимости от инструмента посетитель может выбрать файлы, ввести тексты, URL, значения цветов или CSV/JSON-данные. Эти сведения используются только для выполнения запрошенного расчёта или преобразования в браузере пользователя. JavaScript страницы не отправляет содержимое файлов, значения полей, хеши, результаты сравнения, URL или изображения на сервер владельца сайта.

Для контрольных сумм и поиска дубликатов файлы читаются через File API и обрабатываются Web Crypto API. Для фотографий применяются createImageBitmap и Canvas API. Результат создаётся в памяти вкладки и может быть сохранён пользователем на своё устройство через обычную загрузку браузера.

2. Хранение данных

Сайт не создаёт учётных записей и не ведёт собственную базу пользовательских документов или текстов. Загруженные файлы и результаты находятся в памяти вкладки и удаляются браузером при закрытии или перезагрузке страницы. Тексты остаются в полях текущей страницы; сайт не сохраняет их в localStorage, cookies или на сервере.

Единственное значение, сохраняемое страницей в localStorage, — цветовая тема интерфейса. Это значение не содержит файлов, введённого текста или идентификатора пользователя и не отправляется владельцу сайта.

3. Сетевые обращения и сторонние поставщики

Страница не загружает сторонние JavaScript-библиотеки, рекламные SDK, аналитические счётчики или API для обработки файлов. Все инструменты используют встроенные браузерные API. Содержимое PDF, изображения, тексты и результаты не передаются третьим сторонам кодом этой страницы.

Сайт размещён на GitHub Pages. GitHub как хостинг может самостоятельно обрабатывать техническую информацию о запросах к своим серверам (например, IP-адрес, время обращения, запрошенный ресурс и параметры браузера) в соответствии со своей политикой конфиденциальности. Владелец сайта не получает журналы хостинга и не ведёт собственную базу посетителей.

4. Ограничения

Обработка фотографий через Canvas создаёт новый файл из декодированных пикселей и не переносит исходные EXIF-метаданные, но не скрывает сведения, видимые на самом снимке. При пересохранении GIF-анимация может быть преобразована в статическое изображение. Сжатие до целевого размера не гарантируется для любого изображения.

Хеш SHA-256/SHA-512 помогает сравнивать целостность файлов, но сам по себе не доказывает безопасность файла или достоверность его источника. Сравнение текстов работает построчно и при превышении установленного объёма переходит в упрощённый режим.
