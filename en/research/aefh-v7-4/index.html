AEFH v7.4: mathematical core, expanded proofs and physical constructions

Version 7.4 expands the operator-algebraic appendices for data processing and semifinite resolvent identities. Part A states mathematical results; Part B contains ten conditional physical constructions whose assumptions remain explicit.

Numerical test status: 21/21 checks passed in both standard Python and optimized mode (-O).

The test suite checks finite-dimensional examples and regression properties. Passing tests does not prove an assertion for every von Neumann factor or replace analytic domain and convergence arguments.

Status and scope

The manuscript distinguishes three levels: operator-theoretic statements with their hypotheses, finite-dimensional numerical checks, and physical interpretations that require additional postulates. The last category is not promoted to an experimentally established theory.

In v7.4, Appendix A.4 makes the finite-dimensional channel construction explicit for every pair MN → MK. Appendix A.5 expands the factorization and resolvent identities, positivity of the two integral representations, the local Hessian comparison, the global entropy–affinity bound, and the Petz-contraction route to data processing.

1. The operator functional

For normal states ρ and σ, the programme studies

Iα(ρ, σ) = SAraki(ρ ‖ σ) + α · (1 − F1/2(ρ, σ)) J̃γ = I−γ

where SAraki is Araki relative entropy and F1/2(ρ,σ) = Tr(ρ1/2σ1/2) is the Petz–Hellinger affinity. In finite dimensions the trace convention is normalized; in type II∞ the states are normalized with respect to a normal semifinite trace.

2. Mathematical thresholds

A.1 · Local stability

Local Hessian threshold 4

KBKM(a,b) / KH(a,b) = 2(r + 1) ln(r) / (r − 1) ≥ 4 r = √(a/b)

Equality is attained on the commuting spectral diagonal. The value 4 is a Hessian threshold, not a guarantee of a local minimum: at the critical value a specific commuting path has a negative quartic term −7t⁴/96 + O(t⁶).

A.2 · Global inequality

Universal global threshold 2

SAraki(ρ ‖ σ) ≥ −2 ln F1/2(ρ,σ) ≥ 2(1 − F1/2(ρ,σ))

The first inequality is the order-1/2 to order-1 relative Rényi comparison; the second follows from −ln x ≥ 1−x. The constant 2 is sharp as a universal infimum.

A.3 · Finite dimension

Exact threshold γN for σ = IN

γN = ln(N/(N−1)) / (1 − √((N−1)/N)) = 2 + 1/(2N) + 7/(24N²) + 5/(24N³) + O(N⁻⁴)

This is the exact threshold for the fixed maximally mixed reference state in the stated simplex problem.

A.4 · Data processing

DPI iff α ≥ 0

For α ≥ 0, monotonicity follows from the data-processing inequalities for relative entropy and Petz affinity. For α < 0, an explicit trace-preserving CP construction gives a strict violation for every N,K ≥ 2.

A.5 · Semifinite setting

Type II∞ extension

The expanded appendix treats comparable, possibly unbounded densities, resolvent representations, local second variations, the global bound, and the channel contraction argument. A separate finite-matrix test is described as a regression check only.

Numerical audit

21-test master bench

The same suite runs in standard Python and with python3 -O. Tests cover selected matrix identities and examples; they are not machine proofs of the infinite-dimensional theorems.

3. Appendix A.4 · Explicit finite-dimensional necessity witness

For N,K ≥ 2, define Θ:MN→MK through Kraus operators

A0 = √(K/N) |1K⟩⟨1N| Arj = √(K/[N(K−1)]) |rK⟩⟨jN|, 2≤r≤K, 2≤j≤N Θ(X) = Σℓ Aℓ X Aℓ*

Then ΣAℓ*Aℓ = (K/N)IN and the normalized traces are preserved: τK(Θ(X)) = τN(X). The strictly positive state σK = Θ(IN) is

σK = (K/N) diag(1, (N−1)/(K−1), …, (N−1)/(K−1)).

Set Ψt(Y) = (1−t)Y + t τK(Y)σK and Φt = Ψt∘Θ. For ρN(x)=diag(x,(N−x)/(N−1),…), the output is exactly Θ(ρN(u)), where u=x+t(1−x). With γ=−α>0, the functional reduces to

J̃γ(ρN(x), IN) = gN(x)/N gN(x) = x ln x + (N−x) ln((N−x)/(N−1)) − γ[N − √x − √((N−1)(N−x))] lim(x→0+) √x · gN'(x) = γ/2 > 0.

Thus gN is strictly increasing on some interval (0,δ]. Choosing x=δ/2 and t=δ/[2(1−δ/2)] gives u=δ and a strict increase of the functional, contradicting DPI. The type II1 construction uses three equal-trace projections and a channel that averages a swap of two output sectors.

4. Appendix A.5 · Resolvents and the type II∞ extension

Comparable densities and resolvent identity

Assume ρ,σ ∈ L1(M,Tr)+,1 and λ1σ ≤ ρ ≤ λ2σ as quadratic forms, with 0<λ1≤λ2<∞. The form comparison yields a bounded K∈M such that

ρ1/2 = K σ1/2 X = ρ − σ = σ1/2(K*K − I)σ1/2 Rρ(t) = (ρ+t)−1, Rσ(t) = (σ+t)−1 Rσ(t) X Rρ(t) = Rσ(t) − Rρ(t) = Rρ(t) X Rσ(t), t > 0.

Two non-negative integral representations

SAraki(ρ ‖ σ) = ∫₀∞ t · Tr(Rσ X Rρ X Rσ) dt 1 − F1/2(ρ,σ) = (1/π) ∫₀∞ √t · I2(t) dt I2(t) = Tr(σ1/2 Rσ X Rρ X Rσ) ≥ 0

Positivity is expressed as a quadratic form: with At=XRσ(t), the first integrand is Tr(At*RρAt)≥0. With Ct=Rσσ1/2Rσ≥0, the second is Tr((XCt1/2)*Rρ(XCt1/2))≥0. The limiting arguments use spectral truncation, a joint spectral measure for left and right multiplication, integrable logarithmic bounds, and L² convergence of the square-root functional calculus.

Local and global comparisons

KBKM(a,b) = (ln a − ln b)/(a−b), KBKM(a,a)=1/a KH(a,b) = 1/(√a+√b)² KBKM/KH = 2(r+1)ln(r)/(r−1) ≥ 4

The ratio gives the local Hessian comparison; the equality case is the commuting diagonal. The global type II∞ inequality is

SAraki(ρ ‖ σ) ≥ −2 ln F1/2(ρ,σ) ≥ 2(1 − F1/2(ρ,σ)).

Data processing through the Petz contraction

For a normal trace-preserving channel Φ*, let A=Φ*(ρ), B=Φ*(σ), H1=Δρ,σ, and H2=ΔA,B. The Petz contraction V, obtained from Kadison–Schwarz, satisfies the form inequality

‖H1 1/2 Vξ‖₂ ≤ ‖H2 1/2 ξ‖₂.

The resolvent dilation

Ws = [ (H1+s)1/2 V(H2+s)−1/2 s1/2(I−V*V)1/2(H2+s)−1/2 ]ᵀ

is contractive. Integrating the associated resolvent inequality with the fractional-power weight yields monotonicity of Qp(ρ,σ)=Tr(ρpσ1−p) for 0<p<1. The choice p=1/2 gives affinity DPI; the limit p↑1 gives Araki entropy DPI, including support-mismatch cases.

For α<0 in type II∞, a three-projection counterexample gives a strict increase of the functional. In σ-finite factors, a common strictly positive bounded tail strengthens the example to faithful bounded input and output states. The matrix test suite checks finite-dimensional surrogates; it does not replace the operator-algebraic proof.

5. Ten conditional physical constructions

The programme includes constructions for entropic gravity, coupled quintessence, central decomposition, gauge-theory edge sectors, Wilson-type actions, fundamental charges, a U(2) symmetry-breaking toy model, a Higgs-like potential, Standard Model anomaly constraints, and a finite chiral Dirac operator. Each depends on additional assumptions, couplings, representations, or Yukawa data.

Physical status.

No independent numerical prediction not already supplied as an input is claimed at this stage. The minimal U(2) toy model gives sin²θW≥1/2 and is explicitly not a realistic electroweak fit. The coupled-quintessence integration is a mechanism demonstration, not a likelihood fit to DESI data.
