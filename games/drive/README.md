Drive Horizon — браузерный 3D-симулятор

Открыть игру: https://ivanivorontsov-sudo.github.io/games/drive/

Статическая WebGL-игра для GitHub Pages. Сервер, аккаунт, установка и сборка не нужны.

Возможности: извилистая 3D-трасса с бордюрами и отбойниками, процедурные деревья, дома, озеро и окружение; свободная езда с трафиком; столкновения с машинами, ограждениями и деревьями (импульс, искры, урон); сигнал с реакцией трафика; эффекты дыма, следов, пыли и вспышек; четыре ракурса (погоня, кабина, капот, сверху); выбор Spectral GT RS (по умолчанию) или дорожного SUV Kenney с раздельными настройками вращения колёс; расширенный процедурный 3D-салон с лобовым стеклом, стойками, рулём, креслами и динамической приборной панелью; внешний кузов скрывается только в режиме водителя, чтобы не перекрывать дорогу; PBR-материалы и отражения; постобработка bloom и пресеты качества «низкая / средняя / высокая» с автопонижением по FPS; фары и стоп-сигналы; день/закат/ночь с настоящими фонарями; выбор окраски; сенсорное управление с сигналом и ручником; полноэкранный режим; очки, комбо за близкий разъезд, чекпоинты, локальный рекорд и звук двигателя, шин, ветра и столкновений.

**Контроллеры:** Gamepad API для геймпадов и совместимых рулей. В меню «Руль / геймпад» выбираются устройство, ось руля, оси/кнопки газа и тормоза, ручник, инверсия педалей и чувствительность. Сигнал на геймпаде — кнопки 2, 3 или 5 (X / Y / RB). Из-за различий в раскладках конкретных моделей может потребоваться ручное назначение.

Управление: W/стрелка вверх — газ; S/стрелка вниз/Space — тормоз и задний ход; A/D/стрелки — поворот; Shift — ручник; H — сигнал; C — перебор четырёх камер; кнопка камеры на смартфоне — переключение «погоня / кабина»; F1 — настройки контроллера; R — заново; P/Esc — пауза.

На смартфоне: поворот кнопками слева, газ и тормоз справа, сигнал и ручник по центру. Страница не зумится и не прокручивается во время езды. Если 3D-сцена не создаётся, игра показывает ошибку, а не молча зависает.

Технологии: Three.js 0.187.0 (MIT), GLTFLoader, EffectComposer, UnrealBloomPass, WebGL 2, Gamepad API, HTML, CSS, Vanilla JavaScript. Звук синтезируется в браузере, отдельные аудиофайлы не нужны.

**Модель по умолчанию:** Spectral GT RS (CC0 asset из отдельного публичного репозитория); альтернативный автомобиль — Kenney Car Kit 3.1 SUV (CC0 1.0). Выбор машины сохраняется локально. Оси вращения колёс задаются отдельно для каждой модели; при недоступности GLB остаётся резервная процедурная машина.
