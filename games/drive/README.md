Drive Horizon — браузерный 3D-симулятор

Открыть игру: https://ivanivorontsov-sudo.github.io/games/drive/

Статическая WebGL-игра для GitHub Pages. Сервер, аккаунт, установка и сборка не нужны.

Возможности: извилистая 3D-трасса, процедурная разметка и окружение, свободная езда, трафик, четыре ракурса (погоня, кабина, капот, сверху), выбор Spectral GT RS (по умолчанию) или дорожного SUV Kenney с раздельными настройками вращения колёс; расширенный процедурный 3D-салон с лобовым стеклом, стойками, рулём, креслами и динамической приборной панелью; внешний кузов скрывается только в режиме водителя, чтобы не перекрывать дорогу, PBR-материалы и отражения, постобработка bloom, день/закат/ночь, выбор окраски, сенсорное управление, полноэкранный режим, локальный рекорд и звук двигателя.

**Контроллеры:** Gamepad API для геймпадов и совместимых рулей. В меню «Руль / геймпад» выбираются устройство, ось руля, оси/кнопки газа и тормоза, ручник, инверсия педалей и чувствительность. Из-за различий в раскладках конкретных моделей может потребоваться ручное назначение.

Управление: W/стрелка вверх — газ; S/стрелка вниз/Space — тормоз и задний ход; A/D/стрелки — поворот; Shift — ручник; C — перебор четырёх камер; кнопка камеры на смартфоне — переключение «погоня / кабина»; F1 — настройки контроллера; R — заново; P/Esc — пауза.

Технологии: Three.js 0.187.0 (MIT), GLTFLoader, EffectComposer, UnrealBloomPass, WebGL 2, Gamepad API, HTML, CSS, Vanilla JavaScript.

**Модель по умолчанию:** Spectral GT RS (CC0 asset из отдельного публичного репозитория); альтернативный автомобиль — Kenney Car Kit 3.1 SUV (CC0 1.0). Выбор машины сохраняется локально. Оси вращения колёс задаются отдельно для каждой модели; при недоступности GLB остаётся резервная процедурная машина.
