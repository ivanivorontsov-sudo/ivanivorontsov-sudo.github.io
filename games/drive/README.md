Drive Horizon — браузерный 3D-симулятор

Открыть игру: https://ivanivorontsov-sudo.github.io/games/drive/

Статическая WebGL-игра для GitHub Pages. Сервер, аккаунт, установка и сборка не нужны.

Возможности: живописная 3D-трасса, процедурная разметка и окружение, свободная езда, трафик, камера преследования/капот/сверху, день/закат/ночь, выбор окраски, сенсорное управление, полноэкранный режим, локальный рекорд и звук двигателя.

Управление: W/стрелка вверх — газ; S/стрелка вниз/Space — тормоз и задний ход; A/D/стрелки — поворот; Shift — ручник; C — камера; R — заново; P/Esc — пауза.

Технологии: Three.js 0.187.0 (MIT), WebGL 2, HTML, CSS, Vanilla JavaScript. Внешняя модель автомобиля Kenney Car Kit 3.1 (CC0 1.0) загружается из репозитория car-simulator; при её недоступности используется процедурная модель.
