Drive Horizon — браузерный 3D-симулятор

Открыть игру: https://ivanivorontsov-sudo.github.io/games/drive/

Статическая WebGL-игра для GitHub Pages. Сервер, аккаунт, установка и сборка не нужны.

Возможности: извилистая 3D-трасса, процедурная разметка и окружение, свободная езда, трафик, четыре ракурса (погоня, кабина, капот, сверху), настоящий 3D-интерьер с рулём, креслами и приборной панелью, детализированный спортивный автомобиль, PBR-материалы и отражения, постобработка bloom, день/закат/ночь, выбор окраски, сенсорное управление, полноэкранный режим, локальный рекорд и звук двигателя.

**Контроллеры:** Gamepad API для геймпадов и совместимых рулей. В меню «Руль / геймпад» выбираются устройство, ось руля, оси/кнопки газа и тормоза, ручник, инверсия педалей и чувствительность. Из-за различий в раскладках конкретных моделей может потребоваться ручное назначение.

Управление: W/стрелка вверх — газ; S/стрелка вниз/Space — тормоз и задний ход; A/D/стрелки — поворот; Shift — ручник; C — перебор четырёх камер; кнопка камеры на смартфоне — переключение «погоня / кабина»; F1 — настройки контроллера; R — заново; P/Esc — пауза.

Технологии: Three.js 0.187.0 (MIT), GLTFLoader, EffectComposer, UnrealBloomPass, WebGL 2, Gamepad API, HTML, CSS, Vanilla JavaScript.

**3D-модель автомобиля:** Spectral GT RS, 263 объекта, включая кузовные панели, стекло, салон, подвеску, тормоза и механические элементы. Модель распространяется автором JaronKBragg7337 под лицензией CC0 1.0: https://github.com/JaronKBragg7337/spectral-gt-rs. При недоступности внешнего GLB остаётся резервная процедурная машина.
