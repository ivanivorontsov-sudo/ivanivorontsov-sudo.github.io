Drive Horizon — браузерный 3D-симулятор

Открыть игру: https://ivanivorontsov-sudo.github.io/games/drive/

Статическая WebGL-игра для GitHub Pages. Сервер, аккаунт, установка и сборка не нужны.

Возможности: живописная 3D-трасса, процедурная разметка и окружение, свободная езда, трафик, камера преследования/кабина/капот/сверху, приборная панель и руль в режиме от первого лица, постобработка с bloom, день/закат/ночь, выбор окраски, сенсорное управление, полноэкранный режим, локальный рекорд и звук двигателя.

**Контроллеры:** Gamepad API для геймпадов и совместимых рулей. В меню «Руль / геймпад» выбираются устройство, ось руля, оси/кнопки газа и тормоза, ручник, инверсия педалей и чувствительность. Из-за различий в раскладках конкретных моделей может потребоваться ручное назначение.

Управление: W/стрелка вверх — газ; S/стрелка вниз/Space — тормоз и задний ход; A/D/стрелки — поворот; Shift — ручник; C — смена четырёх камер; F1 — настройки контроллера; R — заново; P/Esc — пауза.

Технологии: Three.js 0.187.0 (MIT), EffectComposer, UnrealBloomPass, WebGL 2, Gamepad API, HTML, CSS, Vanilla JavaScript. Внешняя модель автомобиля Kenney Car Kit 3.1 (CC0 1.0) загружается из репозитория car-simulator; при её недоступности используется процедурная модель.
