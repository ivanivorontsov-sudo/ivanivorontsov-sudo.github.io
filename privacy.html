Политика конфиденциальности

Последнее обновление: 16 ноября 2026 года

Открытый исходный код: исходники сайта и браузерных инструментов доступны для самостоятельной проверки в публичном репозитории GitHub. Для отдельных проектов ссылки на их репозитории размещены в каталоге проектов.

Кратко: Владелец сайта не устанавливает собственную аналитику посещений, рекламные пиксели, аккаунты, формы отправки, чат или серверную загрузку файлов. Основная мастерская и умный поиск обрабатывают файлы, текст и поисковые запросы в браузере; обычные рабочие данные существуют только в памяти вкладки. Отдельный Local Plus хранит только зашифрованную пользовательскую базу в IndexedDB на устройстве по инициативе пользователя. При этом GitHub Pages и отдельные CDN могут получать технические сведения сетевых запросов, включая IP-адрес, User-Agent, URL и время обращения. Эти технические данные обрабатываются соответствующими поставщиками по их политикам.

1. Владелец сайта

Сайт является статическим каталогом и набором браузерных инструментов. На сайте нет формы отправки, пользовательского кабинета, комментариев, чата или серверной загрузки файлов владельцу сайта. Не направляйте владельцу сайта персональные данные, документы, пароли или иные конфиденциальные сведения.

2. Данные при использовании проектов

При обычной работе статических страниц и браузерных инструментов выбранные файлы, введённый текст, результаты расчётов, локальные заметки и содержимое локальных хранилищ не отправляются на мой сервер. На сайте нет формы загрузки файлов, личных кабинетов, рекламных пикселей, собственной аналитики посещений или журнала действий пользователей.

Сетевые обращения всё же возможны. GitHub Pages и CDN получают технические сведения, необходимые для доставки страниц и ресурсов, например IP-адрес, параметры браузера, запрошенный адрес и время обращения. Отдельные функции могут отправлять выбранные пользователем сведения напрямую внешнему API, поисковой системе, ИИ- или почтовому сервису. Такие поставщики получают соответствующий запрос непосредственно от устройства и обрабатывают его по своим правилам; я не получаю копии этих запросов и не имею доступа к внутренним журналам поставщиков. Конкретные внешние обращения перечислены в описании соответствующего проекта.

3. Хостинг GitHub Pages

Сайт размещён с использованием GitHub Pages. GitHub как поставщик инфраструктуры может самостоятельно обрабатывать техническую информацию о запросах к своим сервисам, например IP-адрес, сведения об устройстве и браузере, дату и время обращения, запрошенные страницы и журналы безопасности/диагностики. Такая обработка осуществляется GitHub на основании его собственных условий и политики конфиденциальности, а не через отдельную базу посетителей, созданную владельцем сайта.

Подробнее: Политика конфиденциальности GitHub.

4. Отдельные сторонние плагины и внешние сервисы

Отдельные плагины, расширения и дополнения, которые пользователь самостоятельно находит, устанавливает и запускает отдельно от продуктов владельца сайта, могут быть разработаны и предоставляться независимыми третьими лицами. Они не являются продуктами владельца сайта, не создаются для него и не работают по его поручению. Их разработчики или поставщики самостоятельно определяют, собирают ли они данные и как именно их обрабатывают.

Владелец сайта не получает данные, которые такие независимые компоненты могут передавать своим разработчикам или владельцам компонентов. По вопросам их обработки данных следует обращаться к соответствующему разработчику или поставщику и изучать его политику конфиденциальности.

GitHub, магазины приложений, почтовые сервисы, платёжные площадки и внешние API работают по собственным правилам. Открытие внешней ссылки переводит пользователя на отдельный ресурс. Если сторонний сервис используется внутри конкретного продукта, описание его сетевых обращений приведено в политике этого продукта.

5. Сайт интерактивного конвертера единиц и валют

На сайте интерактивного конвертера единиц и валют расчёты физических величин выполняются непосредственно в браузере. Для отображения валютных курсов браузер отправляет запрос к внешнему сервису ExchangeRate-API, в котором указан код исходной валюты. Введённая сумма и выбранная целевая валюта обрабатываются локально и не отправляются этому API. Внешний сервис может самостоятельно обрабатывать технические сведения о сетевом запросе по своим правилам. Подробности: отдельное уведомление о конфиденциальности конвертера.

6. Отправка данных владельцу сайта

Сайт не предоставляет форму, личный кабинет, комментарии, чат или функцию загрузки пользовательских документов на мой сервер. Браузерные инструменты выполняют выбранные операции на устройстве посетителя. Я не получаю содержимое выбранных файлов, текст из полей, результаты расчётов, локальные заметки или локальную базу браузера через обычную работу сайта. Если посетитель добровольно отправит мне письмо, сообщение или публикацию через GitHub, я могу увидеть только сведения, которые он сам решил отправить; это отдельное обращение, а не автоматический сбор сайтом.

Не отправляйте через публичные сообщения, GitHub Issues или другие внешние площадки пароли, платёжные реквизиты и документы, если это не требуется для обращения. Переданные таким способом сведения становятся доступны соответствующей платформе и адресату по её правилам.

7. Хостинг и технические запросы

Страницы доставляются через GitHub Pages. При обычном HTTP-запросе хостинг может обрабатывать технические сведения, необходимые для доставки и безопасности сайта, например IP-адрес, User-Agent, запрошенный URL, время запроса и технические журналы. В коде сайта нет собственной аналитики посещений, рекламных пикселей, трекеров, форм или передачи журнала посещений владельцу сайта. Внутренние журналы хостинга обрабатываются GitHub по его собственным правилам; ознакомьтесь с политикой конфиденциальности GitHub.

PDF Мастер при открытии загружает PDF.js, pdf-lib, PDF worker, таблицы CMap, стандартные шрифты и WASM-ресурсы с публичных CDN. Сами HTTP-запросы загрузки этих библиотек не содержат выбранные PDF-файлы, однако загруженный JavaScript выполняется в контексте страницы и получает документы для обработки. Поэтому CDN и поставщики библиотек являются границей доверия: при компрометации поставщика изменённый код теоретически мог бы получить доступ к документам в памяти страницы. В Портале инструментов загружается исполняемый JavaScript Tailwind с cdn.tailwindcss.com без закреплённой версии, а также CSS Font Awesome с публичного CDN. Скрипт Tailwind выполняется в контексте страницы и технически может читать её DOM, включая введённый текст; проверенный код портала не отправляет содержимое полей или файлов этому поставщику, но внешняя зависимость остаётся риском цепочки поставок. Генератор QR-кодов в портале переведён на локальную библиотеку и не отправляет текст QR-кода внешнему QR-сервису. В локальной мастерской OCR, Whisper, ИИ и PDF-движки не подгружаются с CDN: для них предлагаются отдельные программы, которые пользователь устанавливает и запускает самостоятельно.

8. Локальная обработка и её границы

Большинство браузерных инструментов выполняет обработку на устройстве посетителя. В новой локальной мастерской и в умном поиске выбранные файлы, их метаданные, извлечённые фрагменты, заметки и поисковый каталог находятся только в оперативной памяти открытой вкладки и очищаются после её закрытия или перезагрузки. Эти функции не отправляют пользовательское содержимое на сервер владельца сайта.

Отдельная функция Local Plus является локальным менеджером паролей и зашифрованным файловым сейфом: пользователь по собственной инициативе создаёт или открывает хранилище, в котором записи, файлы и метаданные шифруются в браузере с помощью AES-GCM, а зашифрованные данные сохраняются в IndexedDB профиля браузера на устройстве пользователя. Владелец сайта не получает пароль, ключ или содержимое хранилища через сайт. Пользователь может экспортировать и удалить свою локальную базу; очистка данных сайта также удалит её.

PDF Мастер обрабатывает документы на устройстве и не отправляет PDF как файл или HTTP-запрос на сервер CDN. Однако загруженные с CDN библиотеки JavaScript исполняются в браузере и получают содержимое документа для разбора. Поэтому CDN — внешняя граница доверия: при компрометации поставщика подменённый код теоретически мог бы получить доступ к PDF в памяти страницы. Версии PDF.js и pdf-lib закреплены, но это не исключает риск компрометации CDN или поставщика. Для максимально чувствительных документов используй установленную офлайн-программу PDF Arranger.

Передача P2P идёт напрямую между браузерами. Сигналы соединения могут содержать сетевые адреса и передаются самим пользователем второму участнику через выбранный им канал. Владелец сайта не получает передаваемые файлы или текст сообщений. Внешние AI-чаты и другие сторонние сервисы открываются только по действию пользователя; поисковый текст не добавляется автоматически в их URL.

Статические банковские реквизиты и кнопки их копирования размещены только на главной странице в разделе «Поддержать автора». Копирование выполняется только после явного нажатия пользователем. На остальных сайтах показывается верхняя карточка со ссылкой на этот раздел; номера карт не дублируются в коде дочерних сайтов. Код сайтов не читает буфер обмена, не отправляет скопированное значение на сервер и не создаёт платёж. Перевод пользователь выполняет отдельно через приложение или сайт своего банка; платёжные данные обрабатывает банк по собственным правилам. На сайтах нет платёжного виджета или формы ввода банковских реквизитов.

Справочник полезных веб-инструментов содержит ссылки на независимые сервисы. При переходе на них браузер обращается к соответствующему поставщику; сведения, которые пользователь вводит непосредственно на внешнем сайте или в его форме, обрабатываются уже этим поставщиком. В карточках отдельно отмечены локальный, смешанный и внешний режимы обработки.

10. Правовые границы и проверка законодательства

Это уведомление описывает фактические функции сайта, но само по себе не определяет, кто является оператором персональных данных, и не подтверждает соблюдение всех требований законодательства. По статье 3 Федерального закона № 152-ФЗ статус оператора зависит от того, кто организует обработку персональных данных и определяет её цели и состав действий; отсутствие собственной базы или формы регистрации само по себе не является универсальным освобождением от обязанностей.

Если в проект добавляются сбор персональных данных граждан РФ, формы, регистрация, аналитика, профилирование или передача внешнему поставщику, перед запуском необходимо отдельно проверить применимость требований к локализации баз данных по части 5 статьи 18, опубликованию политики и мерам по статье 18.1, уведомлению по статье 22 и трансграничной передаче по статье 12 в редакции с изменениями Федерального закона № 265-ФЗ от 26.07.2026. Текст 152-ФЗ · Федеральный закон № 265-ФЗ.

Применимость GDPR оценивается по территориальным критериям статьи 3 Регламента (ЕС) 2016/679; одной доступности статического сайта из страны ЕС недостаточно, чтобы автоматически сделать вывод о применимости всех обязанностей GDPR. Для проектов, целенаправленно предлагающих услуги людям в ЕС или отслеживающих их поведение, требуется отдельная оценка. Официальный текст GDPR.

Законодательство, применимость исключений и фактический статус каждого продукта зависят от конкретной деятельности и могут меняться. Этот текст — информационное описание, а не юридическое заключение.

Карточка поддержки на страницах проектов

На главной странице размещена одна карточка с реквизитами добровольной поддержки. На других собственных страницах общий локальный скрипт добавляет только ссылку на раздел поддержки на главной странице. Номера банковских карт не дублируются на дочерних сайтах; скрипт не копирует их в буфер обмена, не собирает платёжные сведения, не обращается к платёжному API и не принимает переводы. Перевод выполняется пользователем отдельно в приложении или на сайте выбранного банка. Статические CSS и JavaScript-файлы карточки загружаются с GitHub Pages; хостинг может получать стандартные технические сведения HTTP-запросов.

Иностранные агенты и экстремистские материалы

Внешний сервис не признаётся запрещённым только на основании страны происхождения, языка, хостинга или открытой лицензии. Статус иностранного агента проверяется по актуальному реестру Минюста; перечень организаций, признанных экстремистскими, и федеральный список экстремистских материалов — по отдельным перечню организаций и списку материалов. Эти списки имеют разный предмет и не взаимозаменяемы.

Согласно пункту 96 официального перечня Минюста, Meta Platforms Inc. указана в связи с Facebook и Instagram; в той же записи Минюст уточняет, что решение суда от 21.03.2022 и апелляционное определение от 20.06.2022 не распространяются на WhatsApp. Это узкое пояснение к указанному решению, а не универсальная гарантия отсутствия иных ограничений. На страницах проектов не используются встроенные виджеты, SDK или рекламные вставки Facebook/Instagram.

Федеральный закон № 255-ФЗ применяется с учётом актуальной редакции от 26.06.2026 (215-ФЗ). Запрет рекламы на информационных ресурсах иностранных агентов введён 42-ФЗ и действует с 22.03.2024; отдельные новые ограничения для социальной рекламы по 215-ФЗ вступили в силу 01.09.2026, а некоторые положения этого закона вступят в силу 24.12.2026. Статья 13 Федерального закона № 114-ФЗ касается распространения материалов, признанных экстремистскими, а также их производства или хранения в целях распространения. Иностранное происхождение инструмента само по себе не устанавливает ни один из этих статусов.

Первоисточники: 255-ФЗ, 215-ФЗ от 26.06.2026 и сроки вступления норм, 114-ФЗ, статья 13, 38-ФЗ, статья 5. Реестры динамические; перед подключением нового внешнего поставщика, рекламной площадки или SDK необходима повторная проверка.
