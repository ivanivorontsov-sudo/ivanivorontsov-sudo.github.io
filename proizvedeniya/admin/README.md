# Публикационный портал — временно отключён

Портал управления публикациями отключён по решению владельца сайта.

- Файл конфигурации Decap CMS удалён.
- Публичная страница /proizvedeniya/admin/ является статической информационной страницей.
- Нет формы входа, загрузки Decap CMS, OAuth-потока или активного backend-коннектора.
- Уже опубликованные материалы, каталоги и генерация статических страниц не затронуты.

## Текущий порядок публикации

Новые произведения добавляются владельцем сайта вручную через проверенный процесс публикации в GitHub. Не добавляйте config.yml, OAuth-интеграции, токены или сторонние скрипты редактора без отдельного решения владельца и проверки безопасности.

## Возобновление портала в будущем

Перед повторным включением потребуется отдельная проверка поставщика CMS, разрешений GitHub App, точного списка доступных репозиториев, многофакторной аутентификации, процесса отката и журналирования изменений. Предпочтителен минимальный доступ только к нужному репозиторию. Секреты и токены нельзя хранить в публичных файлах сайта.

Публичные произведения остаются публичными; отключение редактора не меняет режим доступа к самим страницам.
