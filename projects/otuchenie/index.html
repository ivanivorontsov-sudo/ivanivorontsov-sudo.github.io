Отучение

Отучение — Android-приложение самопомощи для людей, которые хотят сократить вредное азартное поведение или вернуть контроль над видеоиграми. В нём есть короткая пауза, дневник мыслей, план защиты и справочные материалы. Это не медицинское приложение: оно не диагностирует и не лечит, не заменяет специалиста и не гарантирует результат.

Какие инструменты есть в приложении?

README перечисляет 10-минутную паузу, карточки последствий, КПТ-дневник, калькулятор времени и денег, план защиты, действия после срыва и базу знаний со ссылками на материалы ВОЗ и NICE.

Где хранятся записи?

В README указано, что аккаунта, аналитики, рекламных SDK и сетевых разрешений нет, а практические записи и отметки чек-листов сохраняются локально в SharedPreferences.

Заменяет ли приложение специалиста?

Нет. Сам проект прямо указывает, что не оказывает медицинскую помощь, не диагностирует и не лечит. При выраженных последствиях или кризисе следует обратиться за профессиональной помощью.

Системные требования и сборка

Android 7.0 и новее. Точные команды сборки, версии зависимостей и инструкции для конкретного выпуска опубликованы в README репозитория.

Частые вопросы

Для какой платформы создано Отучение?

Для Android 7.0 (API 24) и новее, согласно README.

Нужен ли аккаунт?

По README — нет; записи сохраняются локально на устройстве.

Является ли приложение терапией или диагностикой?

Нет. Это информационный инструмент самопомощи, не заменяющий профессиональную помощь.
