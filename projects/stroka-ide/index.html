Строка

Строка — мобильная среда разработки для Android: редактор исходного кода, запуск Python и JavaScript, встроенный компилятор языка «Понятный», голосовой ввод, Git/GitHub и чат с ИИ. Подсветка дополнительных языков не означает, что каждый из них можно запустить на телефоне.

Android 8+Стабильная версия 1.8.3MIT
Характеристики, требования и ограничения на этой странице сверены с README репозитория. Перед установкой сверяйте инструкции и состав актуального выпуска с исходным проектом.

Что умеет запускать Строка?

Python запускается через Chaquopy, JavaScript — во встроенной WebView-среде, а язык «Понятный» компилируется во встроенный JavaScript-runtime. HTML и CSS можно просматривать через WebView. Подсветка остальных языков не равна полноценной компиляции.

Как устроен голосовой ввод?

Доступны системное распознавание Android, встроенный офлайн-движок при поддержке устройства и модели Vosk. Для загрузки Vosk нужна сеть; после установки модель работает локально.

Как работает чат с ИИ и Git?

Строка поддерживает Git/GitHub и чат в API-режиме либо через веб-чаты. Работа внешних веб-чатов зависит от авторизации и изменений сайтов-провайдеров.

Системные требования и сборка

Android 8.0 и новее. Точные команды сборки, версии зависимостей и инструкции для конкретного выпуска опубликованы в README репозитория.

Частые вопросы

Какая версия Android нужна?

Android 8.0 и новее (minSdk 26).

Все ли языки из подсветки можно запускать?

Нет. README отдельно описывает запуск Python, JavaScript и «Понятного»; подсветка остальных языков не означает запуск.

Нужен ли интернет для офлайн-голоса?

Интернет нужен для загрузки модели Vosk. После установки модель работает локально.
