## Веб-мастерская

- Проверка сигнатуры файла, размера, MIME, расширения и SHA-256.
- Сверка SHA-256 с ожидаемым контрольным значением.
- Шифрование и расшифрование файлов в формате MTRXENC1: AES-256-GCM, PBKDF2-HMAC-SHA-256, случайная соль и IV.
- Пересохранение изображений с очисткой встроенных метаданных, изменение размера и конвертация JPEG/PNG/WebP.
- Локальное декодирование аудио и экспорт PCM WAV.
- Проверка и форматирование JSON, Base64 и URL-кодирование UTF-8.
- Очистка невидимых Unicode и bidi-символов, нормализация Unicode.
- Удаление распространённых рекламных и аналитических параметров из URL.
- Генерация паролей через криптографический генератор случайных чисел.
- Прямая передача файлов между браузерами по WebRTC DataChannel с ручным обменом SDP без сервера сигнализации.

## Приватность

Веб-мастерская не подключает сторонние JavaScript-библиотеки, API, аналитику, рекламные SDK и не отправляет выбранные файлы на сервер сайта. Обработка выполняется через стандартные браузерные API: File API, Canvas, Web Crypto, AudioContext и WebRTC. Сама GitHub Pages обслуживается GitHub и обрабатывает технические запросы к хостингу.

PDF Мастер работает с содержимым PDF локально, но загружает библиотеки PDF.js и pdf-lib с публичных CDN. CDN получают технические сведения о запросе библиотеки, но не сами PDF-файлы.

Настройки и пользовательские файлы не сохраняются в аккаунт или localStorage веб-мастерской. При прямой передаче используется DTLS-шифрование WebRTC; без STUN/TURN соединение может работать только при возможности прямого сетевого маршрута, например в одной локальной сети.

## Ограничения

- Хеширование, шифрование и расшифрование выполняются в памяти браузера. Для больших файлов требуется значительный объём ОЗУ; на этой странице установлен лимит до 100 МБ для шифрования.
- Сброс пароля невозможен. Потеря парольной фразы означает потерю доступа к зашифрованному файлу.
- Очистка EXIF создаёт новое изображение из пикселей. Анимированный GIF может стать статичным; визуально видимые сведения на фотографии не удаляются.
- Аудиоконвертация зависит от кодеков браузера; экспорт выполняется в PCM WAV.
- P2P-передача использует ручной обмен SDP и прямые ICE-кандидаты без STUN/TURN; через некоторые NAT и разные сети соединение не установится.
- Браузер не может полноценно обновлять драйверы, сканировать весь диск, устанавливать программы, выполнять системные резервные копии, запускать локальный антивирус или гарантированно проверять произвольные серверные HTTP-заголовки.
- OCR, продвинутая транскрибация, перевод и генерация ИИ требуют локальных моделей или внешних вычислений и не включены как фиктивные кнопки.
