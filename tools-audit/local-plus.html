Гармоничная палитра

Local Plus · Все инструменты выполняются в браузере. Парольный сейф использует Web Crypto API (PBKDF2 + AES-256-GCM), IndexedDB и экспорт зашифрованного контейнера. Потеря мастер-пароля означает потерю доступа к сейфу. Это не замена специализированному менеджеру паролей с аудитом безопасности. Не используй этот сайт на чужих или заражённых устройствах. Для документов и сложного офисного редактирования используй локальный LibreOffice; для многодорожечного видео — Kdenlive; для удалённого доступа — RustDesk.
