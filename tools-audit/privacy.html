Политика приватности

Для раздела «100 инструментов: ограничения, реклама и приватность» и его локальной веб-мастерской. Дата: 11 ноября 2026 года.

Главное: новые инструменты в workbench.html обрабатывают выбранные файлы и введённый текст внутри браузера. Они не отправляют пользовательское содержимое на сервер сайта, не используют рекламные SDK, аналитику, аккаунты или сторонние JavaScript-библиотеки.

Какие данные обрабатываются локально

  • Файлы, выбранные для проверки сигнатуры, хеширования, разделения, объединения и шифрования.
  • Фотографии, аудио и видео, выбранные для локального преобразования.
  • Текст, JSON, URL и парольные фразы, введённые в поля инструментов.
  • Файлы, принятые или отправленные через WebRTC P2P-соединение.

Обработка выполняется браузерными интерфейсами File API, Web Crypto API, Canvas API, AudioContext, MediaRecorder и WebRTC. Результаты предлагаются для скачивания. Пароли и файлы не сохраняются через localStorage и не помещаются в облачный аккаунт сайта.

Технические запросы к хостингу

Статические файлы страницы размещены на GitHub Pages. При открытии сайта GitHub может обрабатывать технические сведения обычного HTTP-запроса, такие как IP-адрес, время запроса, User-Agent и технические журналы хостинга. Это относится к доставке самой страницы и не означает, что выбранные для обработки документы загружаются в репозиторий.

Service Worker и офлайн-режим

Service Worker кеширует только статические файлы приложения: HTML-страницы, manifest и иконку. Пользовательские документы, текст, пароли и результаты обработки в кеш не записываются. Кеш позволяет повторно открыть интерфейс при отсутствии сети после первого успешного посещения.

Прямая передача между браузерами

Инструмент P2P использует WebRTC DataChannel и DTLS-шифрование. Сервер сигнализации, STUN и TURN не используются: параметры соединения обмениваются вручную. Работоспособность зависит от сетевой топологии и настроек NAT/брандмауэра. Предложение и ответ SDP могут содержать сведения о сетевых интерфейсах или адресах, поэтому их следует передавать только получателю через доверенный канал. При установлении соединения сами файлы передаются непосредственно между браузерами.

PDF Мастер

Страница PDF Мастер обрабатывает содержимое выбранных PDF в браузере, но загружает программные библиотеки PDF.js и pdf-lib с публичных CDN. CDN получают технические сведения о запросе библиотеки. Сами PDF-файлы этой странице не отправляются на CDN. Условия сторонних CDN регулируются их собственными политиками.

Внешние ссылки каталога

Каталог содержит ссылки на официальные страницы программ и сервисов. При переходе на внешний сайт его владелец может собирать данные согласно собственной политике конфиденциальности. Ссылки открываются отдельно от локальной обработки и не получают автоматически содержимое файлов из мастерской.

Ограничения

Браузерная обработка зависит от возможностей браузера, памяти устройства и поддерживаемых форматов. Страница не является независимым аудитом безопасности браузера или криптографической реализации. Для критически важных архивов рекомендуется проверять резервные копии и контрольные суммы отдельным доверенным инструментом.
