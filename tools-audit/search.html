Локальный индекс файлов

Выберите папку или несколько файлов. Поиск учитывает имена, расширения, MIME-типы, размеры, даты и доступные встроенные метаданные.

Файлы не загружаются в интернет. В IndexedDB сохраняются только извлечённые сведения; содержимое текстовых файлов индексируется только по вашему выбору и остаётся в браузере.

PDF: извлекаются доступные незапакованные Info-поля и видимые маркеры страниц, без OCR и разбора сжатых объектов. Для DOCX/XLSX/PPTX и OpenDocument извлекаются доступные core properties; текст документа целиком не индексируется. Для JPEG читается часть EXIF; GPS-координаты не извлекаются.

Единый запуск популярных ИИ-чатов

Напишите запрос один раз, затем открывайте нужные сервисы. Для каждого запуска запрос копируется в буфер обмена, а сам чат открывается на официальном сайте. Вставить и отправить запрос нужно внутри выбранного чата: общего безопасного способа отправлять сообщения из этой мастерской сайты не предоставляют.

Доступность, бесплатные лимиты, вход и функции зависят от страны и аккаунта. Это интеграция с веб-интерфейсами, а не единое API-подключение; API-ключи не запрашиваются и не сохраняются.

Как устроен умный поиск

Как работает поиск с опечатками?

Запрос нормализуется, затем сравниваются целые фразы, отдельные слова, начала слов и похожие последовательности символов. Для коротких опечаток применяется расстояние редактирования; также проверяется вариант текста, набранный в неправильной раскладке русской/английской клавиатуры. Это локальный алгоритм ранжирования, а не внешняя нейросеть.

Какие фильтры файлов поддерживаются?

Можно фильтровать по type, ext, mime, размеру и дате. Примеры: type:pdf, ext:jpg, size:>10mb, after:2025-01-01, before:2026-01-01, has:dimensions, has:duration, meta:автор.

Что извлекается из метаданных?

Для изображений считываются размеры, а для JPEG — доступные EXIF-поля камеры, даты и автора. Для аудио считываются длительность и базовые ID3-теги MP3, для видео — длительность и размеры кадра. Для PDF читаются доступные незапакованные поля Title, Author, Subject, Keywords и видимые маркеры страниц; для DOCX/XLSX/PPTX и ODT/ODS/ODP — доступные core properties из ZIP-пакета. Отсутствие поля не означает, что сведения отсутствуют внутри файла.

Мастерская передаёт мои файлы или запросы ИИ на сервер?

Индексирование файлов и нечёткий поиск выполняются в браузере. При запуске ИИ-чата запрос копируется в буфер обмена и открывается сайт провайдера. Текст запроса передаётся провайдеру только после вставки и отправки внутри его интерфейса.
