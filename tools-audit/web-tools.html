Приватность и ограничения

Страница не подключает рекламу, аналитику, внешние библиотеки или CDN. Случайные значения формируются через Web Crypto API. Все операции выполняются локально.

Отправляются ли введённые данные на сервер?

Нет, содержимое полей не включается в запросы сайта. GitHub Pages отдаёт только статические файлы.

Проверяет ли декодер JWT подпись?

Нет. Он декодирует открытые части JWT, но не подтверждает подлинность токена.
