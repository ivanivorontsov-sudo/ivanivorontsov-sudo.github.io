Как работает конвертер

Для пересчёта используется базовая единица измерения «джоуль». Сначала исходное значение переводится в базовую единицу, затем — в целевую. Для некоторых физических величин коэффициенты и условия измерения могут быть приближёнными; обратите внимание на обозначение единицы.

Формула: результат = исходное значение × коэффициент исходной единицы ÷ коэффициент целевой единицы.

Введённые числа обрабатываются локально в браузере. На сервер отправляются только статические файлы страницы. Результат показывается с точностью до 12 значащих цифр; для научных и нормативных измерений проверьте стандартную константу и необходимую точность.
